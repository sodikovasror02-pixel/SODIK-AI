SODIK AI — версияи PWA барои Android/Chrome

Ин баста барои кушодан ҳамчун веб-барнома ва насб кардан аз Chrome омода шудааст, аммо барои насби PWA бояд дар суроғаи HTTPS ҷойгир карда шавад. Файли ZIP-ро танҳо ба Chrome кушодан кофӣ нест, зеро Chrome одатан PWA-ро аз файли маҳаллӣ насб намекунад.

Чӣ гуна истифода мешавад:
1. Баста бояд дар хостинги HTTPS ҷойгир карда шавад.
2. Суроғаи сайтро дар Chrome-и Android кушоед.
3. Менюи ⋮ → Install app ё Add to Home screen-ро интихоб кунед.
4. Маълумоти молиявӣ дар localStorage-и ҳамон браузер нигоҳ дошта мешавад.
5. Баъзе функсияҳои овозӣ аз дастгирии браузер ва забони тоҷикӣ вобастаанд.

Ин версия APK нест. Барои он ки корбар аз Chrome насб кунад, файли сайт бояд онлайн бо HTTPS дастрас бошад. AI-и интернетӣ ба он пайваст нашудааст.
